# Security policy

Security fixes target the latest preview release and the current `main` branch.

## Report a vulnerability

Email [manishrelani4598@gmail.com](mailto:manishrelani4598@gmail.com) privately with a description, affected version or commit, steps to reproduce, and the potential impact. If GitHub's **Report a vulnerability** option is available, you can use [private reporting](https://github.com/manishrelani/telegram-media-downloader/security/advisories/new) instead.

Do not disclose an unpatched vulnerability in a public issue. Never include Telegram sessions, login/QR codes or private chat content in a report; use synthetic examples where possible.

For ordinary bugs, installation problems and feature requests, use the [issue tracker](https://github.com/manishrelani/telegram-media-downloader/issues).
