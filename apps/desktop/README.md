# Desktop app

The Flutter frontend for Telegram Media Downloader. It communicates with the local Go backend through JSON Lines over stdin/stdout.

- [Project overview and downloads](../../README.md)
- [Use the app](../../docs/GETTING_STARTED.md)
- [Build and test from source](../../docs/DEVELOPMENT.md)
- [Contribute](../../CONTRIBUTING.md)
- [Troubleshoot](../../docs/TROUBLESHOOTING.md)

Build the backend, patched runtime and preview helper together from the repository root before starting Flutter. The development guide contains the exact commands and tested toolchain. Maintained macOS host files are included; Windows/Linux native distribution remains experimental.
