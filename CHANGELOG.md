# Changelog

Published versions and downloads are available on [GitHub Releases](https://github.com/manishrelani/telegram-media-downloader/releases).

## [v0.1.0-alpha.1](https://github.com/manishrelani/telegram-media-downloader/releases/tag/v0.1.0-alpha.1) — macOS preview

Initial macOS version:

- Browse Telegram channels, groups and forum topics, with recent media and loading of older files.
- Select videos, images, audio and document categories for individual or whole-topic/chat downloads.
- Track file progress, retry unfinished work and inspect saved files.
- Filter and sort media and download history, with progressively loaded video thumbnails.
- Use light/dark appearance, keyboard navigation and a resizable chat sidebar.
- Preserve completed files on storage errors and detect recorded downloads across chat-title/caption changes.
- Bundle the patched tdl runtime and thumbnail helper.

First-time Telegram login uses Terminal. This preview is for Apple Silicon, ad-hoc signed and not notarized. Broader real-account, interruption/recovery and macOS-version testing remains open.
